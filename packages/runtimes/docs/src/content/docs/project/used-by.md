---
title: Projects using it
description: Projects that check their Luau docs with luau-web-checker.
---

- **[wow-forever-luau-types](https://github.com/Braden1996/wow-forever-luau-types)**: strict Luau definitions for a
  game client's addon API, generated from the vendor's documentation. Its
  [docs site](https://braden1996.github.io/wow-forever-luau-types/) checks every guide example against the 1.7 MB
  definitions file. Hovering an API name opens its card from the generated reference. A test also runs the checker
  over the project's sample code and expected-failure files, alongside luau-lsp.
- **[luau-true-myth](https://github.com/Braden1996/luau-true-myth)**: `Maybe`, `Result` and `Task` for strict Luau.
  Its [docs](https://braden1996.github.io/luau-true-myth/) show the inferred types of its examples: generic
  instantiation, refinement of tagged unions, and exhaustive matching.

Using it too? Open a pull request that adds your project to this page.
